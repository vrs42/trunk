 Instructions for generating OS/8 system

 Compile buil50.pa

 .r pal8
 *dsk:buil50<dsk:buil50

 .r absldr
 *buil50$

 .sa dsk buil50

 Create new Build with all available handlers

 .ru dsk buil50
 $lo KL8E
 $lo PT8E
 $lo LPSS
 $lo EDITOR
 $lo TD8ESY
 $lo TD8EA
 $lo SI43SY
 $lo SI43NS

 $pr

 KL8E: TTY
 PT8E: PTP  PTR
 LPSS: LPT
 EDIT: EDOU EDIN
 TD8E: SYS  DTA0 DTA1
 TD8A: DTA0 DTA1
 SISY: SYS  RKA0 RKB0
 SIDK: RKA0 RKB0 RKA1 RKB1 RKA2 RKB2 RKA3 RKB3

 ctrl/c

 .sa dsk buil5x

 Make binary file via SV2BN program

 .ru dsk sv2bn
 *dsk:buil5x.bn<dsk:buil5x.sv

 Generate physical binaries with ptp driver
 store them in ...\pdp8\local\V50\Init

 .r pip
 *ptp:<dsk:buil5x.bn/b

 .r pip
 *ptp:<dsk:os850.bn/b

 .r pip
 *ptp:<dsk:cd50.bn/b

 Generate blank volume with the aid of ConvertDisk

 Mount this disk on unit 0 of disk drive

 Mount Buil5x binary on PTR high speed reader

 Be sure that location 7600 is 0000

 Boot with BIN loader high speed

 Load address 200 and go

 $sys=SISY
 $dsk=sys
 $insert rest of handlers

 Mount os850.bn on PTR

 $build

 $LOAD OS/8: PTR:

 Mount cd.bn on PTR

 $LOAD CD: PTR:

 $boot

 .sa sys buil5d
