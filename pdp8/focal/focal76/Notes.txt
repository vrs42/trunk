This is a reconstruction of the version of FOCAL which I was working on in 1976.

The printed listing I have has markings on it, which correspond with the
differences between it and the .BN file which I have from the period.  The
disassembly of that binary has had the comments and other annotation retyped,
and appears here.

In general, the uppercase content closely matches the original.  Comments in
lowercase note changes which need to be made, or for which the rationale seems
questionable.

Notably, the FEXP, FATN, FLOG implementations are missing, and the FCOS and FSIN
implementations need more testing.

	Vince
