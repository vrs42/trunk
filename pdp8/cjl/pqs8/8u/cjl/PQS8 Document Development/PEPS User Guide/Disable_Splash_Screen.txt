Install the  Acrobat or Reader X update (version 10.1.1).

Exit Acrobat or Reader.

Launch Registry Editor (Start > Run > RegEdit).

Browse to "HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Adobe\(product name)\(version)\FeatureLockDown" and create a New Key "cWelcomeScreen".

Within cWelcomeScreen, create a DWORD Value "bShowWelcomeScreen" and set its value to "0."

Restart Acrobat or Reader X.
