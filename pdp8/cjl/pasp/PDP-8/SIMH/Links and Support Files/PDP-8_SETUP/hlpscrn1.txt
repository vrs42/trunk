This utility manages the "PDP-8_DRIVE" environment variable used by all
PDP-8 development packages to define which drive letter volume to
obtain components of the various packages from.

If the "PDP-8_DRIVE" environment variable already exists, it will be
checked for compatibility with this utility. (Program abort will be
provided to allow preservation of an incompatible setting; however, the
development packages will not function.) If the current value of
"PDP-8_DRIVE" is validated, this program can be terminated without
modifying the setting.

The source drive letter will be automatically determined by this
program after validating certain files for proper contents.  The
environment variable will be created in upper case including the
trailing ":" character.

Once the environment variable is set, it is necessary to completely
log off the current profile and log in again to update the setting.
(Note: If fast user switching is enabled, selecting "Switch User" is
not adequate to update the setting.)

The current value of the "PDP-8_DRIVE" environment variable can be
inspected at any time within System Properties on the Advanced tab.
 Press "Environment Variables" and observe the User variables for the
current profile.  The variable "PDP-8_DRIVE" should be set to a value
consistent with the package requirements. (Note: If "PDP-8_DRIVE" is
set as a system variable it must be removed.  This package only works
with user variables for the current profile.)







Please exit Notepad editor now to continue the overall installation.
