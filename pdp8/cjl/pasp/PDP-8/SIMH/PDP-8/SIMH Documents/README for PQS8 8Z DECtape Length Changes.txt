SETTING THE DIRECTORY LENGTH FOR P?S/8 VERSION 8Z DECTAPES

LAST EDIT:  09-AUG-2015	17:00	CJL

THIS TAPE IS SET TO THE TC01/TC08 STANDARD OF 2702 BLOCKS.

THE NUMBER OF DIRECTORY SLOTS IS 60 IN THIS CONFIGURATION.

PREMIUM DECTAPES ARE OCCASIONALLY AVAILABLE WHICH SUPPORT
3300 BLOCKS.  FOR THAT CONFIGURATION THERE ARE 76 DIRECTORY
SLOTS.

WHEN RUNNING P?S/8 UNDER THE SIMH PDP-8 SIMULATOR, "FANTASY"
DECTAPES CAN BE DEFINED UP TO AS MANY AS 7776 BLOCKS.  MAXIMUM
DIRECTORY SLOTS [84] IS OBTAINED USING 3500 BLOCKS.  ANY
ADDITIONAL BLOCKS CAN ONLY BE USED FOR EXTENDED-LENGTH FILE
PURPOSES WITH THE OS8CON UTILITY [THE TFS DIRECTORY CANNOT
HOLD MORE THAN 84 FILE SLOTS].

TO SETUP THE DIRECTORY FOR 84 DIRECTORY SLOTS IN 3500 BLOCKS:

.BLKODT

0:0016.175 /0514 0404
0:0016.176 /2700 3500
S
.

TO SETUP THE DIRECTORY FOR 76 DIRECTORY SLOTS IN 3300 BLOCKS:

.BLKODT

0:0016.175 /0514 0434
0:0016.176 /2700 3300
S
.

TO SETUP THE DIRECTORY FOR 60 DIRECTORY SLOTS IN 2700 BLOCKS:

.BLKODT

0:0016.175 /0404 0514
0:0016.176 /3500 2700
S
.

NOTE:	THE OLD VALUES FOUND WHEN REPLACING DIRECTORY PARAMETERS
	DEPEND ON THE PRIOR USAGE.  THE FIRST TWO EXAMPLES
	ASSUME THE STANDARD SETTING IS BEING CHANGED TO THE NEW
	SETTINGS IN EACH EXAMPLE; THE THIRD EXAMPLE ASSUMES
	RESTORING FROM "FANTASY" SETTINGS TO STANDARD RELEASE
	VALUES.

NOTE:	THE TFS DIRECTORY IMPOSES BLOCK BOUNDARIES.  AS SUCH, 2702
	BLOCK TAPES ARE TREATED AS 2700 BLOCKS.
