BUGS:
The single DF32 version of REST is included, but is actually unsuitable
for any of the systems built here.  Moreover, it expects to be installed
first, so that the directions in the manual for loading it (with the
directory corrupted) will apply.

It is not known if the version of DDT is relevant.


NOTES:
These are built for 8K, so that memory management is enabled.  They should
work fine on all systems.  The exception is that if selecting a non-existant
field on your machine will crash.  In that case, you could build and run
the 4K version instead.
