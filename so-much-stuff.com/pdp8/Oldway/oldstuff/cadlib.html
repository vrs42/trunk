DEC Board Outlines and Edge Connectors:

This library contains several board outlines and edge connector assemblies for common single, double, quad, and hex sized boards compatible with DEC sockets.

You will need to set the "Copper/Dimension" design rule to 25 mils, to eliminate a diagnostic about copper too close to the edge in the edge connectors.

You will also want to set the routing grid to 25 mils (or other submultiple of 100 and 125 mils). Otherwise it will be difficult to route from the edge connector to the components, as the edge connector uses a 1/8" grid, and the components typically use a 1/10" grid.
